# Overview
This is a python project and nextjs demo app for training a model to play tictactoe/ultimate tictactoe using neural MCTS.

# /demo

Contains a NextJS demo app for playing against a UTTT model. 

# /nnmcts

Main src directory containing python code for the model and training environment. 

# /scripts

Various scripts for running training locally, uploading and training in the cloud, and converting the model to a format suitable for the demo app.
